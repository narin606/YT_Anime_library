# Product Plan

## MVP

The first usable version should answer:

> What anime can I legally watch from the indexed YouTube sources, and where did I stop?

MVP:

- home catalogue
- anime details
- genre metadata
- episode list
- YouTube playback
- account/profile
- resume progress
- Continue Watching
- watchlist
- search

## Later

- seasonal/currently-airing discovery
- recently added official episodes
- studio pages
- related/sequel links
- recommendations
- auto-next
- configurable completion threshold
- source fallback
- favourites
- watching/completed/on-hold/dropped states
- ratings/notes
- viewing statistics
- admin source registry
- unresolved match queue
- availability dashboard

## UX principle

Users browse anime, not channels. Source details are an implementation/admin concern unless they affect playback.
